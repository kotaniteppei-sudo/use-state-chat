このリポジトリは、Cloud Run上で稼働するNext.jsアプリケーションです。
インフラの安全なデプロイと運用（教材20のチェックリスト）に準拠した構成になっています。

## 1. コンテナ（Docker Image）の仕様

- **実行ユーザー**: `nextjs` (UID: 1001, 非rootユーザー権限で実行)
- **待受ポート**: `3000`
- **ヘルスチェック**: `GET /api/health`
  - 正常起動時は `HTTP 200 OK` と `{"status":"ok", "revision":"...", "commit":"..."}` を返します。

## 2. デプロイの安全基準（ポリシー）

本番環境へのデプロイは、稼働中のサービスを停止させない「Blue/Green（候補リビジョン）デプロイ」を採用しています。

- **Git SHAの追跡**: デプロイされたコンテナは、環境変数 `GIT_SHA` を通じてビルド時のGitコミットハッシュと1対1で紐づいています。
- **スモークテストの義務**: 新しいリビジョン（候補）は、トラフィック0%の非公開状態でデプロイされます。`/api/health` への認証付きスモークテストに合格した場合のみ、トラフィックの100%切り替えを行います。
- **フェイルセーフ**: スモークテストに失敗した場合、トラフィックの切り替え処理は即座に中止され、本番環境への影響を遮断します。
